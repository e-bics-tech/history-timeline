# 歴史 年表並べ替え

中学生向けに、6つの歴史の出来事を古い順に並べる単発の教材です。
iPad miniのSafariでのタッチ操作を想定し、PCでも利用できます。

## 構成・起動

`index.html`、`style.css`、`app.js`のみで動作します。依存パッケージ、ビルド、DB、認証、保存機能はありません。
このフォルダーの`index.html`をブラウザで開くだけで利用できます。
HTTPで確認する場合は、Pythonがインストールされた環境でこのフォルダーから
`python -m http.server 8000`を実行し、`http://localhost:8000/`を開いてください。

## 使い方

1. 項目をタップして選択し、画面下部の共通↑・↓で移動します。移動後も同じ項目の選択を維持します。同じ項目の再タップで解除、別項目のタップで選択を切り替えます。未選択時は両ボタン、最上段では↑、最下段では↓が無効です。
2. 「回答する」で順序を確定します。各位置の○×と、年を含む正しい順序が表示されます。
3. 「次の6問」で新しい問題に進みます。履歴は保存しません。

## 問題生成

指定の2件を除いた55件を年ごとにまとめ、異なる6年をランダムに抽出し、各年から1件をランダムに選びます。
選んだ6件の表示順をFisher–Yates法でシャッフルします。
前回と6件すべてが同じなら、1件を未選択の年の出来事へ差し替えます。
年単位で抽選するため、すべての出来事が同じ抽選確率になる方式ではありません。
採点は各位置の出来事が正しい位置と一致するかで判定します。

## GitHub Pagesで公開

1. 独立したGitHubリポジトリを作り、このフォルダー内の4ファイルをリポジトリ直下にアップロードします。
2. リポジトリの **Settings → Pages** を開きます。
3. **Build and deployment → Source** を **Deploy from a branch** にします。
4. **Branch** でファイルを置いたブランチ（例：`main`）、フォルダー **/(root)** を選び **Save** を押します。
5. 公開処理が完了したら、Pagesに表示されるURLをiPadのSafariで開きます。

CSS/JSは`./style.css`、`./app.js`の相対パスで参照しているため、
`https://ユーザー名.github.io/リポジトリ名/`のようなサブパスでも利用できます。
アプリのビルドコマンドやnpmインストールは不要です。

## 確認項目

- 初期表示が6件で同一年がなく、年・正解は非表示。
- タップで選択・解除・切り替え。共通↑↓で隣のカードと交換し、端の方向は無効。
- 回答後は6件の○×、正しい年順が表示され、並べ替えは無効。
- 次の問題で年と正解が再び非表示となり、前回と異なる6件になる。
- iPad miniの縦・横画面で横スクロールがなく、ボタンがタップできる。
- リポジトリ相当のサブパスでCSS/JSが読み込まれる。

実際のiPad Safariでの操作確認と公開後URLの確認は、利用前にも行ってください。
